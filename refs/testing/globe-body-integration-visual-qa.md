# Globe Body Integration Visual QA

Validated at 1440 x 900 and 1920 x 1080.

## Required checks

- Generate an ordinary primary world and enter System view.
- Generate the first eligible airless moon.
- Confirm the generated moon replaces its wireframe in System view.
- Enter Globe view for the primary world and confirm generated moon artifacts are counted and used in the orbital presentation.
- Use `Zoom to globe` from the selected generated moon.
- Confirm Globe view targets the selected moon, uses `generated-airless-moon` mode, and displays the generated airless material.
- Return to the primary world from the Globe target status panel.
- Select the star in System view, tilt the camera, and confirm apparent star radius remains bounded instead of swelling with perspective.
- Confirm 35 percent and 50 percent System zoom remain functional.
